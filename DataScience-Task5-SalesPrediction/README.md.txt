# Sales Prediction Using Python

## OASIS INFOBYTE - Data Science Internship

### Task 5: Sales Prediction Using Python

## Project Overview

This project focuses on predicting product sales based on advertising expenditure across different media channels using machine learning techniques.

The project uses advertising spending data from TV, Radio, and Newspaper channels to predict product Sales.

## Dataset

The dataset contains advertising expenditure and product sales data.

The input features are:

- TV
- Radio
- Newspaper

The target variable is:

- Sales

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

1. Load the dataset
2. Explore and understand the data
3. Check for missing values
4. Perform descriptive statistical analysis
5. Create pairplot visualizations
6. Analyze the relationship between advertising channels and sales
7. Create a correlation matrix heatmap
8. Split the dataset into training and testing sets
9. Train regression models
10. Evaluate model performance
11. Compare the models
12. Analyze feature importance
13. Select the best-performing model

## Machine Learning Models

The following regression models are used:

- Linear Regression
- Random Forest Regressor

## Model Evaluation

The models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The best-performing model is selected based on the evaluation results.

## Data Visualization

The project includes the following visualizations:

- Pairplot
- Sales vs TV Advertising Spend
- Sales vs Radio Advertising Spend
- Sales vs Newspaper Advertising Spend
- Correlation Matrix Heatmap
- Feature Importance
- Residual Plot
- Actual vs Predicted Sales

## Conclusion

The Sales Prediction project demonstrates how machine learning regression techniques can be used to predict product sales based on advertising expenditure.

The project analyzes the impact of TV, Radio, and Newspaper advertising on sales and compares multiple regression models to identify the best-performing model.
